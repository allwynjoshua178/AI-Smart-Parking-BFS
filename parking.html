Algorithm Details

How BFS Finds Parking

Breadth-First Search explores all cells at distance d before any cell at distance d+1. Starting from the entrance, it radiates outward through driving lanes, checking each adjacent parking spot. The first free spot it encounters is guaranteed to be the nearest reachable one.

Pseudocode

BFS-PARK(grid, entrance):
  queue ← [entrance]
  visited ← {entrance}

  while queue is not empty:
    cell ← dequeue(queue)
    for each neighbor of cell:
      if neighbor is FREE SPOT:
        return reconstruct_path(cell)
      if neighbor is ROAD and not visited:
        mark visited
        enqueue(queue, neighbor)

  return "No spots available"

Complexity

Time: O(V + E) where V = grid cells, E = adjacencies. Each cell visited at most once.

Space: O(V) for the visited set and queue.

Optimality: BFS guarantees the shortest path in an unweighted graph — the fewest lane segments to traverse.

Why BFS Over Other Algorithms?

vs DFS: DFS may find a distant spot first. BFS always finds the nearest.

vs Dijkstra: All lane segments have equal cost (unweighted), so BFS is optimal and simpler.

vs A*: A* could use Manhattan distance as a heuristic, but with uniform costs BFS already finds the optimum without heuristic overhead.
